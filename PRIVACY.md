# Privacy Policy

**AI Model Switcher** does not collect, store, transmit, or share any personal data or browsing information.

## Permissions

This extension requires the following browser permissions solely to perform its core functionality:

- **activeTab** — To detect which AI site is currently active and switch models on the page.
- **scripting** — To inject the content script that interacts with the AI site's UI.
- **storage** — To store user preferences locally on the device.

## Data Collection

- No personal information is collected.
- No browsing history or activity is tracked.
- No data is sent to any external server or third party.
- No analytics or telemetry is used.

All operations are performed locally within the browser.

## Third-Party Services

This extension interacts with the following websites only when the user is already on them:

- chatgpt.com
- claude.ai
- gemini.google.com

No data is exchanged with these services beyond the standard page interactions required to switch models.

## Changes

If this policy is updated, changes will be posted in this file and included in the release notes.
